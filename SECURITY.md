# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Report security issues privately through the repository owner's GitHub security contact or repository security advisory workflow.

Include:

- affected component
- reproduction steps
- impact assessment
- suggested mitigation, when available

Please avoid including credentials, tokens, or personal data in reports.

## Scope

Security concerns include authentication/authorization flaws, unsafe data exposure, injection vulnerabilities, dependency vulnerabilities, and insecure infrastructure defaults.
